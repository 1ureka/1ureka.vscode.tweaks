# vs-toolkit

一個用於改善 VS Code 使用體驗的個人擴充套件，包含檔案元資料顯示、自訂樣式注入、以系統預設應用程式開啟檔案等功能。

---

## 核心功能

### 檔案元資料顯示

在狀態列顯示當前檔案的元資料。

| 功能名稱       | 功能描述                                                                           |
| -------------- | ---------------------------------------------------------------------------------- |
| 狀態列資訊顯示 | 自動在狀態列顯示當前開啟檔案的建立時間、修改時間與檔案大小                         |
| 任意檔案       | 支援所有檔案類型，包括 VS Code 原生無法開啟的任意二進位檔案（如 .blend、.psd 等）  |
| 圖片專屬資訊   | 針對圖片檔案額外顯示解析度、長寬比、格式、色彩空間、色彩通道數、透明通道等詳細資訊 |
| 切換自動更新   | 監聽 Tab 與 Tab Group 變化，自動更新狀態列顯示內容                                 |

### 自訂樣式注入

以比 Custom JS and CSS Loader 更安全與精細的方式，將已經寫好的個人偏好的字型、主題與 UI 微調注入到 VS Code 中。

| 功能名稱        | 功能描述                                                                 |
| --------------- | ------------------------------------------------------------------------ |
| 安全的 CSP 策略 | 修改而非刪除 Content-Security-Policy，只添加對於 Google Fonts 的外部例外 |
| 命令式管理      | 提供命令來注入、還原與重新注入自訂樣式                                   |
| 備份與還原      | 注入前自動備份原始 html 或 css 檔案，還原時從備份恢復                    |
| Workbench HTML  | 載入 Google Fonts，設定全域字型、移除焦點輪廓線，以及若干 UI 微調        |
| Markdown CSS    | 修改內建 markdown preview 功能的樣式，省去安裝額外擴展的麻煩             |

### 外部應用程式整合

從 VS Code 中以系統預設應用程式開啟檔案。

| 功能名稱     | 功能描述                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| 右鍵選單整合 | 在檔案總管、編輯器 Tab 的右鍵選單中提供「以預設應用程式開啟」選項                                         |
| PDF 檔案攔截 | 攔截 PDF 檔案的開啟行為，避免 VS Code 以文本編輯器載入二進位內容導致凍結                                  |
| 媒體檔案攔截 | 攔截影片與音訊檔案的開啟行為，取代 VS Code 內建的播放體驗（無聲音、無法與系統整合等問題）                 |
| 安全機制     | 預設允許影片、音訊、DCC 工具存檔 (`.blend, .spp`)、PDF、網頁 (`.html`) 等檔案類型，其餘則會彈出確認對話框 |

## 命令一覽

透過命令面板（`Ctrl+Shift+P`）使用以下命令：

| 命令                 | 說明                                             |
| -------------------- | ------------------------------------------------ |
| `注入自訂樣式`       | 備份原始檔案並注入自訂樣式                       |
| `還原樣式設定`       | 從備份還原所有已修改的檔案                       |
| `還原並重新注入樣式` | 先還原再重新注入，用於更新樣式內容               |
| `以預設應用程式開啟` | 以系統預設應用程式開啟檔案（僅出現在右鍵選單中） |

## 設定

使用樣式注入功能前，需先在設定中填寫 `1ureka.vscodeResourcePath`，指向 VS Code 安裝目錄下的資源路徑。

路徑格式如下：

```
%LOCALAPPDATA%/Programs/Microsoft VS Code/<hash>/resources/app/out/vs
```

> 每次 VS Code 更新後的 `<hash>` 都會改變，因此需要更新此設定並重新使用「注入自訂樣式」命令

## 安裝指南

### 系統需求

- **作業系統**: Windows
- **VS Code**: 1.106.1 或更高版本

### 安裝步驟

1. 前往 [GitHub Releases](https://github.com/1ureka/vs-toolkit/releases) 下載最新的 `.vsix` 檔案

2. 在 VS Code 中安裝擴展：
   - 開啟命令面板（`Ctrl+Shift+P`）
   - 輸入並選擇 `Extensions: Install from VSIX...`
   - 選擇下載的 `.vsix` 檔案

3. 安裝完成後，重新啟動 VS Code
